# Icon Assets

This directory should contain the adapter icon:

- `teslemetry.png` - Main adapter icon (recommended size: 256x256px or larger)

The icon should represent the Teslemetry brand and be clear at various sizes.

For now, you can:
1. Use the Teslemetry logo from the website
2. Create a custom icon combining Tesla and connectivity symbols
3. Use a placeholder until a proper icon is designed

The icon is referenced in `io-package.json` and will be displayed in the ioBroker admin interface.
